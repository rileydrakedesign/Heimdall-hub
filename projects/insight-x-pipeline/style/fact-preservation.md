Fact preservation rules.

Facts that must never change
- Numbers, quantities, prices, percentages, dates, time windows
- Names, titles, organizations, product names, model names
- Cause and effect claims tied to a quoted source
- Any direct quote text

Allowed transformations
- Reorder sentences
- Split or merge sentences without changing meaning
- Replace weak verbs with concrete verbs
- Replace vague nouns with specific nouns, only if supported

Disallowed transformations
- Adding new facts or new claims not present in the source
- Changing units or magnitudes
- Swapping names or attributing claims to the wrong entity
- Changing time references

Validation requirement
- Every post must include a short list of extracted facts in machine readable form during internal generation.
- Final public text must match those facts.
