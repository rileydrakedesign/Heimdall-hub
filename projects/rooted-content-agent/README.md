# Rooted Content Agent

A workflow that takes rooted ideas and references and turns them into informational Instagram carousel posts.

## Outputs (target)
- `runs/<run-id>/carousel/`
  - `plan.md` (slide-by-slide outline)
  - `copy.md` (final copy per slide)
  - `caption.md` (caption + optional hashtag set)
  - `assets/` (source images, screenshots)
  - `slides/` (final slide images)
  - `sources.md` (links and citations)

## Uploads
Put raw inputs here:
- `projects/rooted-content-agent/files/`

Use the dashboard Uploads links (GitHub upload UI) to add from mobile.

## Working rules
- prioritize clarity and information density
- avoid vague motivational content
- every carousel should have a single core promise and a clear takeaway
