# Theme spec (v1)

A carousel run must choose exactly one theme.

## Theme A: Pixel art (nano banana)
Goal
- cohesive pixel art across every slide

Rules
- consistent pixel density and perspective across slides
- limited palette (define 5–8 colors)
- backgrounds should include intentional whitespace for text

Deliverables
- `pixel_art_prompt_prefix.txt`
- `palette.json`
- `reference_board/` (approved examples)

## Theme B: Photo library
Goal
- cohesive photographic style across every slide

Rules
- consistent color grading
- consistent composition patterns that leave whitespace

Deliverables
- `grading_notes.md`
- `reference_board/` (approved examples)
