# Component spec (v1)

## Layout
- max width: 1120–1200
- section vertical spacing: 64–96 desktop, 40–64 mobile
- background: neutral-900

## Header
- left: Class Chat AI wordmark
- right: CTA button

## Hero
- H1 + subhead + CTA
- include one compact proof row or badge

## Proof strip
- 3–4 pill items with small icons

## Demo block
- 3 cards each containing a gif (placeholder) with caption
- keep aspect ratios stable to avoid layout shift

## How it works
- 3 steps with numbers

## Feature cards
- 3 cards, neutral-800 surfaces, subtle border
- include focus and hover states

## FAQ
- accordion with keyboard support and proper aria

## Footer
- minimal

## Interaction states
- focus-visible ring for all controls
- loading states keep original labels
- links use <a>
