## Iteration 1 — “Is it safe?” FAQ copy + credits as packaging primitives (adjacent network-automation category)

### Agent for X — competitors/pricing/packaging
- Taplio (LinkedIn creator automation): pricing makes **AI credits** explicit (e.g., Standard includes “250 AI credit”) and the FAQ turns safety into a conversion primitive with very direct language: “**behaves exactly like a real LinkedIn user would… doesn’t rely on hacks… respects normal usage patterns**.” Even though it’s LinkedIn, the packaging/objection-handling pattern maps 1:1 to X automation fear.
  URL: https://taplio.com/pricing

### Class Chat AI — competitors/pricing/packaging
- Khanmigo: splits pricing cleanly by buyer type — **Teachers: free**, **Learners: $4/month ($44/year)**, **Families: $4/month ($44/year)**, plus **District Tools: request pricing** (SSO/rostering, data, customer success, professional learning on AI). This is a strong “consumer vs district” packaging template for Class Chat AI if it targets both individual learners and institutions.
  URL: https://www.khanmigo.ai/pricing

## Iteration 2 — “All-in-one growth suite” bundles (library + scheduling + automations + CRM)

### Agent for X — competitors/pricing/packaging
- Tweet Hunter: positions itself as a full growth suite bundling **viral tweets library (2M+)**, **scheduling**, **evergreen tweets**, and automation features like **Auto-DM / Auto-plug / Auto-retweet** plus “X CRM.” Also claims “Add unlimited Twitter accounts.” This is a competitor packaging anchor: buyers expect “end-to-end” not just writing.
  URL: https://tweethunter.io/pricing

### Class Chat AI — competitors/pricing/packaging
- Campuswire (pricing norm via press reporting): Campuswire’s “pro version” was described as **$20 per student per term** (at the time), later shifting strategy. Useful as a concrete datapoint for the per-student-per-term mental model in course communication tooling.
  URL: https://campustechnology.com/articles/2020/11/18/campuswire-invites-instructors-to-make-best-courses-available-to-world-and-collect-a-fee.aspx

## Iteration 3 — Incentive alignment + “we don’t sell student data” as explicit competitive positioning

### Agent for X — competitors/pricing/packaging
- (Angle) Creator tools that include automation increasingly have to *prove* the stance (limits + safety) with explicit text. Taplio is a good template for “say it in plain English” safety copy; Tweet Hunter is a template for “bundle the whole loop.”
  URLs:
  - https://taplio.com/pricing
  - https://tweethunter.io/pricing

### Class Chat AI — competitors/pricing/packaging
- Campuswire FAQs: explicitly answers “Is Campuswire FERPA-compliant?” and makes an incentive-alignment claim in plain language (“We don’t sell student data… or advertise.”). This is the kind of copy that becomes a competitive artifact in edu procurement conversations.
  URL: https://medium.com/campuswire/campuswire-faqs-c6993d93cb29

## Iteration 4 — Compliance posture as a top-of-funnel artifact (borrow trust language from best-in-class)

  URL: https://buffer.com/pricing

### Class Chat AI — competitors/pricing/packaging
- OpenAI “Business data privacy, security, and compliance” page: establishes the *reference posture* that many edu buyers now implicitly expect AI vendors to match: “**We don’t train our models on your organization’s data by default**,” **encryption**, and **data retention controls** (including “zero data retention” for qualifying orgs on API). Even if Riley’s products don’t use OpenAI, this is a persuasive benchmark for what “serious” looks like.
  URL: https://openai.com/business-data/
