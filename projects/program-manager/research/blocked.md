# Research Blocklist

Purpose: avoid low-signal sources, unethical tactics, or rabbit holes.

---

## Blocked sources / behaviors
- Any subreddit/community that explicitly forbids product mentions (follow rules).
- Buying fake followers, engagement, or spammy outreach lists.
- “Growth hacks” that rely on deception.
- Over-indexing on competitor feature checklists instead of user language.

## Time-wasters (avoid)
- Endless tool directories without real user quotes.
- Reading hot takes without capturing evidence.

## Allowed exceptions
- If a blocked source is the only place a niche ICP exists, log the rationale + rules before engaging.
