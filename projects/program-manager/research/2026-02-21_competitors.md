## Iteration 1 — Baseline set (creator tools + classroom comms)

### Agent for X — competitors/pricing/packaging
- Tweet Hunter: positioned around “build and monetize your X audience”; bundles scheduling + evergreen queue + Auto-DM/Auto-plug + analytics + “best-in-class AI” / custom model training (packaging leans into automation). Pricing page accessible; useful for feature checklist benchmarking. 
  URL: https://tweethunter.io/pricing
- Typefully: product positioning as multi-network creation/scheduling (X/LinkedIn/Threads/etc). (Pricing page readability extraction was unhelpful today, but privacy policy is accessible and gives clear trust-copy examples.)
  URLs: https://typefully.com/  |  https://support.typefully.com/en/articles/8718444-privacy-policy

### Class Chat AI — competitors/pricing/packaging
- Campuswire: “Where people learn together” and explicitly pitches as replacement for LMS forums + Piazza + Slack + Zoom + iClicker/TopHat (broad packaging: feed + chatrooms + live sessions + lectures). Category anchor: “free forever.”
  URL: https://campuswire.com/

## Iteration 2 — Automation-at-scale packaging + edu trust baggage

### Agent for X — competitors/pricing/packaging
- Taplio (LinkedIn, but packaging is a close analog to X creator automation): tiers map cleanly to AI credits + comment credits; higher tiers add lead database + auto-connection + auto-DM + bulk DMs. Also has explicit “Is Taplio safe?” FAQ framing (“behaves like a real LinkedIn user… doesn’t rely on hacks”). This is *exactly* the pattern we should expect for X (ban/throttle fear mitigation via copy + guardrails).
  URL: https://taplio.com/pricing
- Blocked today:
  - Hypefury pricing (bot verification)
    URL: https://hypefury.com/pricing

### Class Chat AI — competitors/pricing/packaging
- Piazza: privacy policy spells out breadth of collected data (registration, course info, user content, profile info) and explicitly includes a “Children’s Privacy” section + age gating in ToS (Minimum Age). This is the kind of “institutional risk” doc that procurement/IT will read.
  URLs: https://piazza.com/legal/privacy  |  https://piazza.com/legal/terms

## Iteration 3 — Social suites treat X as a priced carve-out + campus AI at scale

### Agent for X — competitors/pricing/packaging
- Metricool: clearly states Twitter/X is an add-on (+$5 per connected account) and that some networks are excluded from the free plan (“except LinkedIn and Twitter”). This is strong evidence buyers are already trained for explicit X carve-outs + add-on pricing due to platform economics.
  URL: https://metricool.com/pricing/

### Class Chat AI — competitors/pricing/packaging
- ChatGPT Edu: campus-scale pitch with explicit “bring AI to campus at scale” framing and privacy/security quote from a university CIO (“protect our student privacy… research output… security requirements”). Even without visible pricing, it sets the competitive bar: procurement-ready language + higher limits than consumer.
  URL: https://chatgpt.com/business/education

## Iteration 4 — Enterprise suite pricing pressure + comms platforms’ privacy positioning

### Agent for X — competitors/pricing/packaging
- Sprout Social: enterprise suite framing with add-ons like Listening + Premium Analytics; the competitive reality is that “Agent for X” can’t out-suite them, but can out-focus them (voice, ideation-to-post loop, safe automation). Pricing page accessible as a packaging reference point.
  URL: https://sproutsocial.com/pricing/
- Blocked today:
  - Buffer pricing (Cloudflare / “Just a moment”)
    URL: https://buffer.com/pricing

### Class Chat AI — competitors/pricing/packaging
- Discord: privacy policy + safety positioning; highlights that Discord doesn’t sell personal info and funds via subscriptions/paid products/sponsored content, plus controls for how content is used. For Class Chat AI, Discord is a “default” alternative for student comms that sets user expectations about privacy controls + retention + moderation.
  URL: https://discord.com/privacy

## Iteration 5 — Compliance baseline artifacts (edu) + “no-training” expectations (AI)

### Agent for X — competitors/pricing/packaging
- Typefully privacy policy: explicit promises about only accessing account to debug + not opening drafts/posts unless asked; deletion within 30 days; encryption in transit; Stripe handles card details. This is the *pricing-page-adjacent* trust artifact we should mirror (even if we ship it as “Security & Automation Policy”).
  URL: https://support.typefully.com/en/articles/8718444-privacy-policy

### Class Chat AI — competitors/pricing/packaging
- FERPA regulatory hub: canonical .gov resource for FERPA regs + links to parent/student guides + the statutory basis (20 U.S.C. 1232g). This should directly inform how we describe roles (school vs vendor), consent, retention, and disclosure.
  URL: https://studentprivacy.ed.gov/ferpa
- OpenAI Privacy Policy: important competitor baseline for what users now expect to be spelled out (user content, connected services, log/usage data, etc.). For Class Chat AI, we should translate this into “what we collect” + “training opt-out/no-training” + retention windows in plain language.
  URL: https://openai.com/policies/privacy-policy/
