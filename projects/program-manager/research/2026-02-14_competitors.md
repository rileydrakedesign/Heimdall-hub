# Competitor / Pricing / Packaging Sweep — 2026-02-14

Scope priority:
1) **Agent for X**
2) **Class Chat AI**

Method: 5 internal iterations. Each iteration adds at least one new source or a materially different angle.

---

## Iteration 1 — Clear, creator-first X writing+scheduling (simple tiers, scheduling horizon as a knob)

### Agent for X — direct-ish competitor benchmark

**Postwise (AI writing + scheduling; plans anchored to AI post quotas + scheduling horizon)**
- Pricing tiers are clean and legible (good benchmark for “creator tool” expectation):
  - Basic: **$37/mo** — 3 social accounts, **500 AI-generated posts/mo**, **3 months scheduling**, 3 custom AI voices.
  - Boss: **$59/mo** — 5 accounts, **1,000 AI-generated posts/mo**, **12 months scheduling**, “advanced analytics dashboard.”
  - Unlimited: **$97/mo** — unlimited accounts, unlimited AI posts, **unlimited scheduling**, “custom AI training.”
- Packaging signal: **scheduling time-horizon** is explicitly tiered (3 months vs 12 months vs unlimited).
- Source: https://postwise.ai/pricing

### Class Chat AI — packaging implication
- “Custom AI training” is an upsell on creator tools; the analog in Class Chat is: **custom course knowledge base / custom rubric / department templates** as the paid unlock.

## Iteration 2 — Document-chat pricing is now “limits as product”: pages, upload size, questions/day, and model menu

### Class Chat AI — doc-chat adjacency (student + researcher use cases)

**AskYourPDF (doc chat; multi-model menu + explicit daily limits)**
- Pricing uses *multiple meters* that shape UX expectations:
  - document limits (pages/doc, upload MB, docs/day)
  - usage limits (questions/day, conversations/day)
  - model access (multiple models listed; some require “credits”)
- Example tier (annual billing shown):
  - Premium: **$11.99/mo billed yearly**; 2,500 pages/doc; 31MB; 50 docs/day; 1,200 questions/day; Knowledge Base + OCR + Chrome extension.
  - Pro: **$14.99/mo billed yearly**; 6,000 pages/doc; 877MB; 150 docs/day; 100,000 questions/day; longer reply length + priority support.
- Source: https://askyourpdf.com/pricing

### Agent for X — packaging implication
- Buyers are being trained to accept “model access” menus (and “credits required” for premium models). For Agent for X: “voice model / reasoning mode / safety mode” can be explicit tier toggles.

## Iteration 3 — Competitor packaging expands from “write + schedule” into “engage + outreach automation”

### Agent for X — adjacent (LinkedIn) but the packaging pattern matters

**Taplio (AI writing + scheduling + engagement + outreach; heavy automation upsells)**
- Clear tier ladder with big jump to “automation/outreach”:
  - Starter: **$32/mo billed yearly** (shows $39 monthly equivalent)
  - Standard: **$49/mo billed yearly** (shows $65)
  - Pro: **$149/mo billed yearly** (shows $199)
- Pro tier bundles high-risk/high-value automations:
  - lead database, auto-connection requests, **auto-DM**, bulk DMs.
- Trust copy appears inside pricing FAQ: “**Is Taplio safe?** … behaves exactly like a real LinkedIn user would… doesn’t rely on hacks or shortcuts…”
- Source: https://taplio.com/pricing

### Class Chat AI — implication
- “Engagement automation” analog in Class Chat is *not* outreach; it’s **course moderation + triage automation** (auto-tag, duplicate merge, escalation to TA/instructor) as the upsell.

## Iteration 4 — Third-party review sources highlight the “over-automation / spammy” risk as a buyer objection

### Agent for X — competitor review lens

**Tweet Hunter (review write-up; plans + automation features, explicit cons)**
- Pricing cited: **$49–$99/mo**; plans called Discover ($49) and Grow ($99).
- Review flags a recurring objection: **“Potential for over-automation and spammy tactics.”**
- This is the exact trust wedge for “Agent for X”: guardrails + caps + review/approval mode.
- Source: https://softwareoasis.com/tweet-hunter-review-monetize-twitter/

## Iteration 5 — Knowledge-work doc tools price “pages processed” + overage, and sell security language as a feature

### Class Chat AI — doc-chat competitor lens

**Humata (review source; page limits + pay-as-you-go overage; security posture as conversion)**
- Pricing described (review):
  - Free: 60 pages/mo, 10 answers/mo
  - Student: **$1.99/mo**, 200 pages, extra pages **$0.02/page**
  - Expert: **$9.99/mo**, 500 pages, extra pages **$0.02/page**
  - Team: **$49/user/mo**, 5,000 pages, extra pages **$0.01/page**
- Review highlights value prop: answers with citations; plus collaboration/permissions at higher tier.
- Source: https://www.toolsforhumans.ai/ai-tools/humata

### Agent for X — packaging implication
- The analog meter for Agent for X isn’t pages; it’s **(posts + replies + DMs) per month** plus optional “overage” or “API pass-through” pricing.
