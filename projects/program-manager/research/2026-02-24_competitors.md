## Iteration 1 — price points + packaging primitives (baseline anchors)

  - Source: https://socialrails.com/blog/typefully-pricing
- **Hypefury pricing tiers emphasize limits that map to “automation surface area”** (X accounts, scheduling horizon, auto-DM limits, engagement builder, Tweet→Reels limits).
  - Source: https://socialrails.com/blog/hypefury-pricing

### Class Chat AI (course comms / discussion)
- **Campuswire positions “free forever”** and explicitly frames itself as replacing LMS forums/Piazza + adding chatrooms/live sessions.
  - Source: https://campuswire.com/

  - Source: https://stattlc.com/2022/07/29/using-ed-discussion-as-a-course-communication-tool/

## Iteration 2 — competitive feature bundling (what gets bundled together)

### Agent for X
- **Tweet Hunter bundles: content library + AI writing + scheduling/automations + CRM/lead finder + analytics** into one “all-in-one Twitter growth tool” narrative.
  - Source: https://tweethunter.io/competitors/tweethunter
- Packaging pattern: vendors sell **the full loop** (ideas → compose → queue → automate engagement/DMs → analytics) rather than “AI writing” alone.
  - Source: https://tweethunter.io/competitors/tweethunter

### Class Chat AI
- Competitive pattern: course comms tools compete on **workflow primitives** (categories/subcategories, anonymous posting, endorsements/resolution, code blocks, LaTeX) not “chat quality” alone.
  - Source: https://stattlc.com/2022/07/29/using-ed-discussion-as-a-course-communication-tool/

## Iteration 3 — workflow expectations as competitive moat (UX-level competition)

### Agent for X
- **Scheduling ergonomics are table stakes**; differentiators are “queue,” “best time to post,” “evergreen/auto-reschedule,” and safe automations (e.g., thread delay, auto plug, auto DM).
  - Source (feature list): https://tweethunter.io/competitors/tweethunter
  - Source (Typefully workflow primitives): https://socialrails.com/blog/typefully-pricing

### Class Chat AI
- **Ed Discussion student workflow** expectations:
  - required title + category/subcategory
  - **suggests similar threads while typing** (dedupe + knowledge base behavior)
  - anonymous-to-peers vs private-to-staff options
  - Source: https://support.wharton.upenn.edu/help/ed-discussion-for-students
