## Iteration 1 — “X growth suite” pricing ladder: automation + analytics + AI writer are tier separators

### Agent for X — direct-ish competitor benchmark

**Tweet Hunter (X growth suite; pricing ladder + automation bundle)**
- Pricing ladder (as reported in a detailed review):
  - Discover: **$49/mo** (or **$36/mo billed annually**)
  - Grow: **$99/mo** (or **$49/mo** for accounts under 5,000 followers)
  - Enterprise: **$200/mo**
- Tier separators map cleanly to packaging knobs we can copy:
  - Discover = inspiration + scheduling + automation + analytics (no “AI writer”)
  - Grow = adds AI writer + hooks/ideas + performance prediction
  - Enterprise = adds “train a custom model” + AI replies
- Source: https://www.nichepursuits.com/tweet-hunter-review/

### Class Chat AI — pricing implication
- The “Grow discounted for small accounts” pattern is basically an *eligibility gate* (by follower count). Edu analog: **small class / small department pricing** to reduce adoption friction.

## Iteration 2 — Competitor landscape summary (3rd-party) reveals common packaging: entry-tier $19–$49/mo, trust caveat = “robotic” automations

### Agent for X — adjacency benchmark via tool comparison

**Postwise vs Hypefury vs Buffer (comparison article; includes prices + stated pros/cons)**
- Postwise prices summarized:
  - Basic: **$37/mo** (400 AI credits/mo; up to 5 accounts)
  - Unlimited: **$97/mo** (unlimited AI credits; unlimited accounts)
- Hypefury prices summarized:
  - Starter: **$19/mo**
  - Premium: **~$49/mo**

- Source: https://kawaak.com/blog/en/postwise-alternatives-us/

### Class Chat AI — packaging implication
- Creator tools position “GhostWriter / personalized tone” as a paid feature; in Class Chat, the analog upsell is **course-specific behavior** (rubrics, instructor tone, department policies) + admin controls.

## Iteration 3 — Edu discussion platforms normalize term-based + class-size-based licensing (and soften backlash with hardship language)

### Class Chat AI — direct competitor (adjacent) pricing model

**Piazza (instructor + department licenses; priced per term / class size)**
- Instructor license pricing (per term):
  - **$379/term** (max 400 students)
  - **$429/term** (max 700 students)
  - **$479/term** (unlimited class size)
- Department license pricing:
  - **$9,000/year** (up to 2,000 students)
  - **$12,000/year** (up to 3,000 students)
- Positioning note: the article emphasizes “no ads,” a contribution-supported fallback, and “never want money to be the reason you can't use Piazza” (hardship language).
- Source: https://support.piazza.com/support/solutions/articles/48001161300-paid-model-for-piazza-q-a

### Agent for X — packaging implication
- Term-based / seasonal pricing exists even outside B2B; for creators, the analog is **campaign-based / launch-based bundles** (e.g., “30-day launch pack” tier or add-on).

## Iteration 4 — Doc-chat tools compete on trust primitives: citations, side-by-side, and explicit security claims

### Class Chat AI — doc-chat adjacency

**ChatPDF (doc chat; free daily cap + citations + security posture in FAQ)**
- “Free plan” positioning: free to try without signup; FAQ states free plan allows analyzing **2 documents per day**; paid plan (“Plus”) offers “unlimited document analysis” + advanced features.
- Trust posture on the marketing page (FAQ):
  - “Built-in citations”
  - “Side-by-side view” for verification
  - security language: SSL encryption; encrypted storage; claims SOC2 Type II certified storage provider; delete controls
  - model menu transparency (mentions routing between GPT-4o / GPT-4o-mini)
- Source: https://www.chatpdf.com/

### Agent for X — packaging implication
- “Model routing / which model answered” is now a surfaced expectation in some categories; for Agent for X, the analog is **mode selection** (Voice-Lock vs Fast Draft vs Safe Mode) and transparent constraints.
