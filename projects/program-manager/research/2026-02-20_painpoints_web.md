## Iteration 1 — competitors/pricing/packaging (pain points implied by packaging)

### Agent for X
- **Buyers expect an end-to-end “growth loop,” not a writing tool.** Tweet Hunter’s pricing page ladders from “viral tweets library” → scheduling/evergreen → automation (auto-DM/auto-retweet/auto-plug) → analytics → CRM lists.
  - https://tweethunter.io/pricing
- **“Suite bloat” is a real objection**; Typefully explicitly positions itself as a cleaner alternative, implying creators are tired of over-featured dashboards.
  - https://typefully.com/blog/buffer-review-alternative

### Class Chat AI
- **“Free forever” is an adoption magnet in classroom tools** (Campuswire). If we charge, the objection won’t just be “price,” it will be “why isn’t this free like X?”
  - https://campuswire.com/
