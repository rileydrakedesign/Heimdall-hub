## Iteration 1 — “Is it safe?” is now FAQ-level copy (not a hidden policy)

### Agent for X
- Pain points / objections:
  - Primary objection is still account risk; the emerging pattern is vendors answering it **directly in pricing FAQs** with plain language.
- Workflow expectations:
  - Buyers expect **caps/guardrails** + an explanation that the product “acts like a normal user,” not “hacks.”
- Channel / marketing tactics:
  - Pricing pages are doing double duty as trust pages (FAQ copy becomes ads/affiliate collateral).
- Trust / privacy concerns:
  - The winning copy pattern: “no hacks / respects normal usage patterns.”
  URL: https://taplio.com/pricing

### Class Chat AI
- Pain points / objections:
  - Users are split by buyer: teacher (free tool), learner/parent (small subscription), district (procurement).
- Workflow expectations:
  - District tier expectations: SSO/rostering + data/analytics + customer success + professional learning.
- Trust / privacy concerns:
  - Buyers infer “safety posture” from who the product is for (teacher vs child) and what controls are promised.
  URL: https://www.khanmigo.ai/pricing

## Iteration 2 — “All-in-one loop” expectation: library → write → schedule → automate → engage

### Agent for X
- Pain points / objections:
  - Creators don’t want a narrow “AI writer”; they want the full growth loop (including engagement).
- Workflow expectations:
  - Scheduling + evergreen queues are baseline.
  - Automation primitives (Auto-DM / Auto-retweet / auto-plug) appear as standard capabilities.
- Channel / marketing tactics:
  - Big feature lists on pricing pages function as category education (“this is what’s normal now”).
- Trust / privacy concerns:
  - “Unlimited accounts” claims increase scrutiny: buyers will ask about OAuth tokens, access scope, revocation.
  URL: https://tweethunter.io/pricing

### Class Chat AI
- Pain points / objections:
  - In course tooling, buyers are trained to think in **per-student-per-term** units; pricing controversies can become department lore.
- Workflow expectations:
  - Course-native pricing shapes feature expectations (admin controls, governance, integrations).
  URL: https://campustechnology.com/articles/2020/11/18/campuswire-invites-instructors-to-make-best-courses-available-to-world-and-collect-a-fee.aspx
