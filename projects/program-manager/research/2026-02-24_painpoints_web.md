## Iteration 1 — packaging-driven objections ("limits" create friction)

### Agent for X
- Objection: users hit **plan-gated limits** that are tightly coupled to workflows (X-account caps, scheduling horizon, auto-DM limits, conversion limits).
  - Source (Hypefury limits example): https://socialrails.com/blog/hypefury-pricing
  - Source (Typefully tiering): https://socialrails.com/blog/typefully-pricing

### Class Chat AI
- Objection: “free forever” sets buyer expectation; paid tools must justify via governance/integration rather than just UX.
  - Source (Campuswire): https://campuswire.com/
- Objection: **institutional pricing** can kill adoption when instructors can’t expense it.
  - Source (Ed cost): https://stattlc.com/2022/07/29/using-ed-discussion-as-a-course-communication-tool/

## Iteration 3 — workflow expectations (what users assume the product will do)

### Agent for X
- Expectation: “all-in-one” means more than writing—includes:
  - inspiration library/search
  - queue + drafts
  - automations (auto-DM, thread delay, evergreen)
  - analytics + best-time-to-post guidance
  - Source: https://tweethunter.io/competitors/tweethunter

### Class Chat AI
- Expectation: discussion is **structured and searchable**, not a chat stream:
  - categories/subcategories
  - **similar-thread suggestions while composing** (dedupe)
  - private-to-staff vs anonymous-to-peers
  - rich content editor (code, embeds, annotations)
  - Source: https://support.wharton.upenn.edu/help/ed-discussion-for-students

## Iteration 4 — channels/marketing tactics that set buyer expectations

### Agent for X
- Buyers are trained by competitors to expect **affiliate-driven “deal page” narratives** and recurring commissions (which amplifies the spread of pricing/limits claims).
  - Source: https://hypefury.crisp.help/en/article/what-is-the-hypefury-affiliate-program-sus7v3/

### Class Chat AI
- Channel dynamic: positioning as a **replacement for Piazza/LMS forums** with strong testimonials reduces switching cost anxiety.
  - Source: https://campuswire.com/
- Channel dynamic: adoption path often runs through **Canvas/LTI** instead of direct-to-consumer.
  - Source (Canvas integration mention): https://support.wharton.upenn.edu/help/ed-discussion-for-students
