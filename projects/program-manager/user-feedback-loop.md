# User Feedback Loop (v1)

## Intake
Sources:
- support email / DMs
- in-app feedback
- call notes
- social replies

## Triage
Tag each item:
- bug
- usability
- feature request
- pricing
- onboarding
- retention

## Decision
For each theme:
- what’s the underlying job-to-be-done?
- what’s the smallest change that improves the KPI?
- what do we measure after shipping?

## Output artifacts
- `projects/<product>/feedback/inbox.md` (raw)
- `projects/<product>/feedback/themes.md` (grouped)
- `projects/<product>/experiments/backlog.md`

## Close the loop
If a user reports something and we ship a fix:
- notify them (ask-first external action)
- log it in the weekly PM report
