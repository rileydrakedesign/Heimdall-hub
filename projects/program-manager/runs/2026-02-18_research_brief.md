# Research Brief — 2026-02-18

Priority order:
1) **Agent for X**
2) **Class Chat AI**

## What changed / what we learned today (high signal)

### 1) Affiliate programs are now **full-funnel enablement** (not just “here’s a link”)
- Tweet Hunter’s affiliate page includes tiering, long cookie windows, a “free access forever after 10 subs” perk, and a downloadable asset pack. That’s basically sales enablement.
- Source: https://tweethunter.io/affiliates

### 2) “Safe automation” copy is increasingly **behavioral** (“no hacks; normal usage patterns”)
- Taplio’s pricing FAQ answers “Is Taplio safe?” with: behaves like a real user, no hacks/shortcuts, respects normal usage patterns. That’s a crisp template for Agent for X’s ban/throttle fear.
- Source: https://taplio.com/pricing

### 3) Edu pricing norms remain **term-based + class-size shaped**, with explicit backlash-reduction language
- Piazza’s paid-model doc gives concrete per-term pricing by class size and includes “no ads” plus hardship accommodations.
- Source: https://support.piazza.com/support/solutions/articles/48001161300-paid-model-for-piazza-q-a

### 4) Instructor “why we switch tools” is still driven by **workflow primitives**, not AI features
- A real instructor comparison highlights pain with Slack DMs and missing features (anonymous posting, LaTeX, accepted answers, categories); also flags Ed’s tradeoffs (no DMs; no native app).
- Source: https://stattlc.com/2022/07/29/using-ed-discussion-as-a-course-communication-tool/

### 5) Privacy narratives still move departments
- Stanford Daily documents Piazza Network employer access concerns and notes instructors migrating to Ed.
- Source: https://stanforddaily.com/2020/10/04/concerned-with-piazzas-data-privacy-management-some-professors-look-to-alternative-discussion-forums/

## Implications

### Agent for X
- We need an **affiliate-proof canonical artifact**:
  - “Pricing + Limits + Safety Contract” page that’s stable and linkable.
  - a small “Affiliate kit” (approved claims + screenshots + do/don’t) to prevent misinformation.
- We should adopt “safe automation” messaging that is **specific + bounded**:
  - “no hacks,” “human-like cadence caps,” “explicit opt-in,” “1-click revoke,” and “what we never do.”

### Class Chat AI
- For an early wedge, prioritize **workflow primitives** that map to instructor switching reasons:
  - anonymous posting, accepted answers, math/code support, categories, LTI/SSO, moderation/audit.
- If monetization is instructor- or dept-paid, plan the **reassurance layer** from day one:
  - no ads, hardship policy, and clear term-based tiers.
