## 1) Agent for X (priority #1)

### Positioning (tight)
Write and ship X posts **in your voice**, with visible safety controls (caps + approvals + logs) and an explicit trust posture (training/retention/security), so you can stay consistent without account-risk anxiety.

### Differentiation to prove (in-market)
1) **Voice preservation** (anti-generic output).
2) **Controls + auditability** (approvals, change history, “what posted when”).
   - Evidence lane: Typefully shipping “Draft Activity” audit trails for teams.
   - Source: https://typefully.com/changelog
3) **Trust posture as conversion** (SOC2/security kit, non-training claims, retention clarity).
   - Evidence lane: Motion security page reads like enterprise procurement enablement.
   - Source: https://www.usemotion.com/security
4) **Transparent cost/limits** when agentic actions grow (credits/quotas + caps).
   - Evidence lane: Motion publishes credits/seat/month + $/credit; Taplio publishes AI/comment credits.
   - Sources: https://www.usemotion.com/pricing , https://taplio.com/pricing

### Core assets (next 72h)
1) **Trust Pack** (public page) + in-product “Controls” panel
   - Training defaults + retention + deletion
   - “What we access” (e.g., drafts, analytics) vs “what we never access/store”
   - Safety caps (posts/day, edits required, cooldowns) + approval toggles
   - Audit log (“draft created by agent”, “edited by user”, “scheduled”, “published”)
2) **Affiliate-ready landing kit**
   - 1-page pitch + proof + FAQ + UTM
   - Commission + rules (avoid paid ads if desired)
   - Evidence lane: Taplio affiliate playbook.
   - Source: https://taplio.com/affiliates
3) **In-workflow wedge**
   - Lightweight extension/launcher: capture idea → generate 3 drafts → push into queue.
   - Evidence lane: Raycast/agent surfaces are becoming real.
   - Source: https://typefully.com/changelog

### Channels (first tests)
- **Affiliate / creator partners** (micro-creators + operators): ship the affiliate kit; provide swipe copy and a 30s demo.
  - Benchmark: https://taplio.com/affiliates
- **X build-in-public**: ship “Trust Pack” first, lead with caps + audit logs.
- **Integration-led content**: “How to use agents safely for X” (controls-first narrative).

### One experiment (start now)
Landing A/B (single variable):
- A: “Write in your voice”
- B: “Safe posting: caps + approvals + logs”
Success metric:
- visit → waitlist
- scroll depth / clicks on Trust Pack

## 2) Class Chat AI (priority #2)

### Positioning (tight)
District-ready class chat with grounded answers and admin-grade governance, packaged with the rollout collateral districts expect.

### Differentiation to prove
1) **Governance package**: DPA-ready, retention/deletion, admin visibility.
   - Evidence lane: SchoolAI privacy includes explicit vendor + non-training posture.
   - Source: https://schoolai.com/privacy
2) **Implementation enablement as product** (resources, onboarding decks, checklists).
   - Evidence lane: Remind’s resources library.
   - Source: https://www.remind.com/resources
3) **Comms expectations alignment** if touching parents/families:
   - templates + translation + multi-channel broadcast.
   - Evidence lane: ParentSquare mass comm norms.
   - Source: https://www.parentsquare.com/mass-communications/
4) **Trust claims with artifacts** (attestations/third-party verifications).
   - Evidence lane: MagicSchool AI privacy explainer references zero-retention attestations.
   - Source: https://www.magicschool.ai/blog-posts/ai-data-privacy

### Assets to build
1) **District Trust Pack** (admin-facing):
   - subprocessors list
   - training defaults
   - retention/deletion controls
   - audit/observability roadmap
2) **Rollout kit** (PDF/slide):
   - teacher onboarding (30 min)
   - parent comm templates
   - admin checklist (SSO/LMS/rostering)
3) **Comms-mode MVP** (if relevant):
   - message templates + translations + delivery log

### Channels
- District admin outbound (email/LinkedIn): lead with Trust Pack + rollout kit.
- Teacher communities: lead with “reduce tabs + faster planning” only after trust baseline is established.
