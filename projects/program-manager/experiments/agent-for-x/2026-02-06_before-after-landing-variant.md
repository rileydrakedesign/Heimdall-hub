# Experiment — Agent for X: Before/After Landing Variant

**Date:** 2026-02-06

## Hypothesis
If we replace feature-first sections with 3 strong before/after examples (raw → in-your-voice), then the landing page **waitlist conversion rate** will increase because visitors immediately understand the outcome and trust the quality.

## Funnel stage
Acquisition → Signup intent

## Metric
- **Primary:** visit → waitlist submit conversion rate
- **Secondary:** scroll depth to examples section; outbound clicks (if any)

## Segment
- Visitors coming from X posts and creator communities
- English-speaking creator ICP

## Test design
- **Type:** A/B (or sequential test if A/B not available)
- **Variant A (control):** current feature-first page
- **Variant B:** hero + 3 before/after packs + CTA repeated
- **Sample size proxy:** 250 unique visits per variant (or 7-day time-box)
- **Duration:** 7 days

## Stop rule
Stop early if:
- Tracking is broken for >24h, or
- Variant B underperforms by >25% after ≥150 visits.

## Result
Pending

## What we do next
- If win: make before/after packs a required weekly output (min 3/week).
- If loss: rewrite examples (quality issue) and/or reposition around “voice-preserving editor” not “automation.”
