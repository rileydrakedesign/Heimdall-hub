# Distribution Checklist + Templates (Pre-launch)

**Goal:** ship a repeatable distribution motion that doesn’t require “reinventing the post” every time.

---

## Pre-flight checklist (every push)
- [ ] What is the single promise/outcome?
- [ ] What is the proof? (before/after, demo, citation)
- [ ] What is the ask? (waitlist / DM / reply / call)
- [ ] Link has UTM tags
- [ ] Screenshots/gif are readable on mobile
- [ ] Log the push + outcome in `kpis/kpi-log.md`

---

## Channel playbooks

### X (daily)
- [ ] 1 post/day (proof-first)
- [ ] 5 replies/day to ICP accounts (helpful, not salesy)
- [ ] 1 DM/day with concrete offer (when appropriate)

Templates:
- `templates/distribution/x-post.md`
- `templates/distribution/x-thread.md`
- `templates/distribution/x-dm.md`

### Reddit (2–3x/week)
- [ ] Identify 5 threads where you can help
- [ ] Comment help-first; only link if it adds value
- [ ] If posting top-level: follow each sub’s rules strictly

Templates:
- `templates/distribution/reddit-post.md`
- `templates/distribution/reddit-comment.md`

### Short video (3–5 clips/week)
- [ ] 10–20s demo (one moment of magic)
- [ ] On-screen text matches the hook
- [ ] CTA on last frame

Template:
- `templates/distribution/short-video-script.md`
