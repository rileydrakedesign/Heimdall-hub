# 72-Hour Asset Checklist (Pre-launch)

**Goal:** within 72 hours, produce the minimum asset kit required to run meaningful GTM tests.

**Rule:** quality > volume. A single great before/after example beats 10 generic ones.

---

## Universal (applies to every product)

### Instrumentation (must-have)
- [ ] Unique visits tracked (simple analytics OK)
- [ ] Waitlist submits tracked
- [ ] Source tagging (UTMs) for every distribution push
- [ ] A place to log results (see `kpis/kpi-log.md`)

### Core copy (must-have)
- [ ] One-sentence promise (outcome + who)
- [ ] 3 bullets: “Why this is different”
- [ ] 5 objections + crisp answers (FAQ)

### Proof (must-have)
- [ ] 3 before/after packs (see template)
- [ ] 1 short demo video (10–20s)
- [ ] 1 static screenshot collage for quick sharing

### Distribution kit (must-have)
- [ ] X post template (1 short)
- [ ] X thread template (1 long)
- [ ] Reddit post + comment templates
- [ ] A DM outreach script

---

## AIStudyBuddy — 72h kit

### Demo assets
- [ ] 3 demo clips:
  - [ ] “Ask question → cited answer”
  - [ ] “Click citation → jump to page”
  - [ ] “Compare vs ChatGPT hallucination (gentle)”

### Messaging angles (pick 1–2)
- [ ] “Stop trusting hallucinations: verify in your PDF”
- [ ] “Study faster: answers grounded in lecture slides”
- [ ] “Exam week: turn PDFs into a study guide”

### Distribution targets
- [ ] Identify 10 Reddit threads to comment on (help-first)
- [ ] Prepare 5 short vertical video scripts
