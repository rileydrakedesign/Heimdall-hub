# Program Manager (Heimdall Role)

This project defines an always-on **program manager** workflow that Heimdall executes autonomously.

## Scope (C)
- **Internal ops PM:** project tracking, next actions, blockers, decision logs, reminders.
- **Business PM:** GTM strategy, launches, roadmap, KPIs, experiments, user communication + feedback loops, cost/overhead control.

## Outputs (where they live)
- Portfolio war room: `projects/program-manager/war-room.md`
- GTM hypotheses bank: `projects/program-manager/gtm-hypotheses.md`
- KPIs + logging: `projects/program-manager/kpis/`
- Checklists + templates: `projects/program-manager/checklists/` and `projects/program-manager/templates/`
- Experiments: `projects/program-manager/experiments/`
- Feedback: `projects/program-manager/feedback/`
- Dev blockers: `projects/program-manager/dev-blockers.md`
- Ship log: `projects/program-manager/ship-log.md`
- Calendar stubs: `projects/program-manager/gtm-calendar/`
- Project list truth: `data/projects.yaml`
- Daily/weekly run logs: `projects/program-manager/runs/`
- Decisions: `playbook/templates/adr.md` (or a dedicated ADR folder if preferred)

## Operating principles
- Keep updates concrete and skimmable.
- No fluff. No fake certainty.
- Ask before any external actions (emails, posting, payments).
