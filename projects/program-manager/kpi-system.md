# KPI System (v1)

## North-star framing
For each SaaS business, we track:
- **Acquisition:** visits → signup rate
- **Activation:** time-to-first-value, activation rate
- **Retention:** D7/D30 retention, churn
- **Revenue:** conversion to paid, ARPA/ARPU, MRR
- **Referral/virality:** invites, shares (if applicable)
- **Cost:** infra + tools, CAC (when measurable)

## Default KPI pack (0 → 1000 users)
- Weekly active users (WAU)
- Activation rate
- D7 retention
- Signup conversion rate
- Cost per active user (proxy until CAC is real)

## Experiment requirements
Every test must specify:
- hypothesis
- metric(s)
- primary segment
- sample size proxy or time box
- success threshold
- what we’ll do if it wins/loses

## Reporting
- PM daily: deltas, anomalies, actions
- PM weekly: KPI trend + experiment review
