# Rooted Content Agent

## What this is
A content workflow that turns raw inputs into **informational Instagram carousel posts**.

Inputs can include:
- long-form ideas (notes, transcripts)
- short-form ideas (bullets, hooks)
- inspiration Instagram posts (links or screenshots)
- reference sources (web pages, PDFs)

Outputs include:
- a complete carousel plan (slide-by-slide)
- polished copy per slide (headline + body)
- design spec (typography, spacing, layout patterns)
- generated carousel images (or a ready-to-edit source format)
- caption + hashtags strategy (optional)

## Why we’re doing it
The X pipeline proves we can do sectioned extraction + style control + validators.
This project extends the same philosophy to **visual, multi-slide Instagram content**:
- strong information density
- consistent visual system
- repeatable, scalable creation

## Non-goals (for v1)
- fully autonomous posting to Instagram
- growth hacking gimmicks
- complicated animation

## Core constraints
- mobile-friendly workflow
- reproducible templates
- reviewable outputs committed to the hub
