# Distribution Push — Stop Rules + Measurement (Lean)

## Goal
Get **signal**, not vanity metrics: replies, DMs, qualified calls.

## Measurement (track daily)
- Posts published (count)
- Impressions (optional)
- Engagements:
  - replies
  - reposts
  - bookmarks
  - profile clicks
- **Meaningful outcomes (primary):**
  - DMs received
  - DMs sent
  - qualified conversations started
  - waitlist/email captures
  - calls booked

KPI logging lives in: `ops/kpi-log.md`

## First push plan (3 days)
- Day 1: 1 thread + 1 single
- Day 2: 2 singles
- Day 3: 1 thread

## Stop rules (content quality)
Stop / do not post if any are true:
- No quote/source for the central claim.
- Claim depends on a number/stat you can’t cite.
- Post contains a strong prediction without an explicit “my take” label.

## Stop rules (time)
- If a single post takes >30 min to draft twice in a row → reduce format (shorter, fewer claims).
- If a thread takes >60 min twice in a row → reduce to 5 tweets and keep 1 quote.

## Stop rules (distribution)
Stop the push and pivot if after **10 posts** OR **7 days** (whichever first):
- 0 replies + 0 DMs + 0 clicks/captures.

Pivot options:
- Narrow ICP (choose one niche)
- Change hook: “before/after pack” proof
- Swap CTA: from “waitlist” → “I’ll do 1 free pack for 3 people” (only if capacity)

## Win threshold (keep going)
Continue if after 7 days:
- ≥2 qualified conversations OR
- ≥20 meaningful engagements (replies+DMs+clicks+catures)
