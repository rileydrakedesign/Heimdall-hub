# Minimal Intake Workflow — Agent for X

Goal: reduce friction while collecting enough signal to produce good drafts.

## Intake (what the user fills)
**Step 1: Contact + context**
- Name
- Email
- X handle
- What do you do? (1 sentence)

**Step 2: Source material**
- Upload/link: audio/video/transcript (Loom, podcast, call)
- Topic to focus on (choose 1)
- Any “must include” points

**Step 3: Voice + constraints**
- Link 2 example posts that sound like you
- Things to avoid (claims/competitors/politics)
- CTA preference: (Reply / Link / Waitlist / None)

## Internal workflow (operator steps)
1) Confirm receipt within 2 hours.
2) Extract 5–10 candidate insights with quotes/timestamps.
3) Choose 3 insights based on: novelty + relevance + defensibility.
4) Draft: 1 thread + 3 singles + 1 CTA.
5) Quality pass (stop rules in `distribution-stop-rules.md`).
6) Deliver pack + ask 3-question feedback.

## Deliverable format
- Google Doc or Notion page with sections:
  - “Quotes / Evidence”
  - “Thread”
  - “Singles”
  - “CTA variants”

## REQUIRED_INPUT
- Where intake should live (Tally/Typeform/Supabase form/etc.)
- Whether the user can upload files or must provide links only.
