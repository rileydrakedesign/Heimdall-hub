# Weekly Reset Checklist — Agent for X

Timebox: 30 minutes.

## 1) Review KPIs (5m)
- [ ] Posts shipped
- [ ] Replies/DMs
- [ ] Qualified convos
- [ ] Captures/calls

## 2) Review experiments (5m)
- [ ] Which hypothesis was tested?
- [ ] What changed?
- [ ] Keep / kill / repeat?

## 3) Review content quality (10m)
- [ ] Which post performed best? Why (hook, topic, proof, CTA)?
- [ ] Which post felt easiest to write? (use as default format)
- [ ] Any claims you regret / need to clarify?

## 4) Tighten offer (5m)
- [ ] Rewrite one sentence on landing based on real objections.
- [ ] Update CTA if needed.

## 5) Plan next week (5m)
- [ ] Pick 1 ICP lane
- [ ] Choose 3 source recordings
- [ ] Schedule 5 posts

## Outputs
- Update: `ops/kpi-log.md` + `ops/experiments.md`
- Add 1 line to a “lessons learned” section (optional).
