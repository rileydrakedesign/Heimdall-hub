# Cost Sanity Checklist (Minimal) — Agent for X

Goal: avoid “busy demo” that can’t be delivered profitably.

## Per-pack time budget
- Target: **≤ 90 minutes** total
  - Ingest/skim: 15m
  - Insight selection + evidence: 20m
  - Drafting: 30m
  - Edit/QA: 20m
  - Delivery + follow-up: 5m

## Per-pack compute/tooling budget
Track (even rough):
- LLM tokens / model cost (estimate)
- Transcription cost (if any)
- Any paid tools used

## Red flags
- >2 hours per pack consistently
- Needing to research external facts for every post (scope mismatch)
- Too many topics per pack (no lane)

## Guardrails
- Prefer quote-grounded content over “internet research” content.
- Cap at 3 insights per pack.

## REQUIRED_INPUT
- Actual model + cost assumptions in production.
- Target price per pack / per week.
