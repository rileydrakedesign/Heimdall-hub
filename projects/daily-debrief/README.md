# Daily Debrief (Morning Brief)

A daily morning briefing that Riley wakes up to.

## Goal
Deliver a consistent, high-signal brief built from sources Riley cares about.

## What’s in scope
- Current events (general)
- Markets brief (tailored watchlist + movers + why)
- AI / dev brief (papers + news)
- Ops / projects + agent work updates
- Optional: surf + weather

## Where the config lives
- Brief profiles + sources: `data/briefs.yaml`

## Where outputs should be stored
- `projects/daily-debrief/runs/YYYY-MM-DD.md`
