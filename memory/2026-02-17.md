## Skill: isometric pixel-art scenes + consistent assets (Nano Banana Pro)

Goal: Generate a scene first, get user approval, then generate standalone asset images that match the scene’s **style + palette + isometric orientation**.

Update (Riley request): workflow should be **scene → base plate (background+static) → sequential dynamic assets**, with an approval gate after the scene to classify static vs non-static and add/remove assets.

### Research notes (prompt/scaffold)
- Nano Banana Pro guidance emphasizes: **subject, composition, action, location, style**, plus explicitly defining the role of **reference inputs** (e.g., “Image A for style, Image B for pose”).
- For consistency, treat the approved scene image as a **reference input** for each asset prompt and state its role as “style + palette + isometric orientation reference only”.
- Strong constraints help: “pure solid white background (#FFFFFF)”, “no gradient/texture/vignette”, “no text/watermark/logo”, “centered, fills most of frame but fully contained”.
