# Writing & UX Standards

## Defaults
- Clarity > cleverness.
- Short sections, strong hierarchy.
- Avoid feature dumps. Earn the next scroll.

## Landing pages (default rules)
- Single primary CTA.
- 3–4 value bullets max before "how it works".
- 3-step explanation beats paragraphs.
- Address trust objections explicitly (privacy, accuracy, guarantees).

## X posts (default rules)
- Hook fast, then deliver real value.
- Prefer specifics, mechanisms, examples.
- Use whitespace and short lines.
- Avoid generic hype and AI-sounding filler.
