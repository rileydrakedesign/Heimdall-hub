# Playbook (Global Operating Practices)

This is the shared operating system for how Riley + Heimdall build.

## How to use
- If a rule applies across **multiple projects**, it lives here.
- If a rule is **project-specific**, it lives in that project’s folder under `projects/<id>/`.
- Decisions that change direction should be captured as an ADR.
